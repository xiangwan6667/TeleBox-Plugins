# TeleBox-Plugins

基于 [Wyatt323/TeleBox-Plugins](https://github.com/Wyatt323/TeleBox-Plugins) 维护，包含文字语录玻璃气泡样式调整。

## 添加插件仓库

在 TeleBox 聊天中发送：

```text
.tpm source add https://github.com/xiangwan6667/TeleBox-Plugins
```

查看当前自定义源：

```text
.tpm source
```

## 插件功能

| 安装名 | 命令 | 功能简介 |
| --- | --- | --- |
| `tj` | `.tj` | 统计指定消息的全部回复，列出回复用户、时间和消息内容。 |
| `aix` | `.aix` | AI 对话、绘图、模型与提示词等 AI 功能。 |
| `stsave` | `.stsave` / `.st` | 保存贴纸，或将回复的图片、视频等媒体转换后保存到贴纸包。 |
| `ban_ad_spam` | 自动监听 | 别人回复消息并 @你 且包含 `ban广告` 时，自动对目标消息回复 `/spam`。 |
| `yvlux` | `.yvlux` | 根据消息生成语录贴纸，并支持保存到贴纸包。 |

`yvlux` 的文字语录默认使用深紫渐变的玻璃气泡：大圆角、气泡尾巴、细描边和顶部高光，头像靠下对齐，昵称保留发送者的强调色。绘图由 [Quote API](https://github.com/LyoSU/quote-api) 的 `glass` 样式完成，贴纸外围保持透明。

气泡按参考图保持紧凑比例：内边距从约 16px 微增至 18px，圆角约 27px，高光和描边沿用原样式。昵称完整显示且不换行，当前群的成员标签或管理员头衔在旁边以小号文字显示，无底色、无边框。长昵称会撑宽气泡，整张语录统一缩放，保持昵称、标签、正文的字号比例。优先读取消息自带的标签，再查询群成员信息。转发消息不套用转发者的群标签，查不到标签时正常生成。新成员标签需要宿主的 `teleproto` 支持对应 Telegram 协议字段。

背景使用宽柔光、轻微的明暗层次和约 7% 的局部透光，细颗粒强度很低，高光和描边保持原来的粗细。标题文字通过同一绘图接口批量绘制，再由插件完整排版，并缓存最近 64 组昵称与标签以减少重复请求。

文字和媒体语录统一使用 `https://quote.yuri.ly/generate.webp`，真实头像、图片和引用缩略图由插件在本地合成（使用宿主已有的 `sharp`），保留玻璃材质、完整昵称和无框群标签。`r` 支持引用没有配文的图片。视频、GIF 和动态贴纸在语录中使用静态预览；`s` 保存已有贴纸时保留原文件。旧内置媒体接口自动迁移到当前默认接口；其他自定义 API 继续使用自己的地址，后端需要支持 `style: "glass"`。回复消息发送 `.yvlux` 即可生成；发送 `.yvlux api reset` 可恢复默认接口。

## 语录模式与组合

以下生成命令都需要回复一条消息。以该消息为起点，按实际消息的时间顺序计数，排除语录命令和服务消息。

| 模式 | 命令 | 说明 |
| --- | --- | --- |
| 单条 | `.yvlux` | 生成回复的消息 |
| 连续选取 | `.yvlux 12` | 连续选取 12 条，每 5 条自动生成一张 |
| 跳选 | `.yvlux p 1,6,8` | 按实际消息序号选取；旧的 `pick` 写法仍兼容 |
| 带引用 | `.yvlux r 3` | 选取 3 条，并显示它们的回复引用内容 |
| 改名 | `.yvlux n "新名字"` | 修改首条所选消息作者在本次语录中的显示名，同一作者后续消息沿用 |
| 自定义标签 | `.yvlux g "新标签"` | 替换首条所选消息作者的标签，同一作者后续消息沿用；`g ""` 隐藏标签 |
| 自定义文字 | `.yvlux 新的内容` | 替换回复消息的文字 |
| 保存贴纸 | `.yvlux s` | 回复图片或贴纸，保存到已配置的贴纸包 |
| 查看帮助 | `.yvlux help` | 查看命令与组合示例 |

连续选取与跳选二选一；`r`、`n`、`g`、`t` 可以与任意一种选取方式叠加，选项顺序可变。组合时用 `t "文字"` 替换首条所选消息的文字。`n`、`g` 只修改本次语录中首条所选消息的作者，其他作者保留原名和群标签，不修改 Telegram 资料。包含空格或与选项同名的内容，请使用引号。`s`、`config`、`api` 单独使用。

```text
.yvlux 12 r n "新名字"
.yvlux p 1,6,8 n "新的 昵称"
.yvlux r p 1,6,8 n "新名字" g "自定义标签" t "替换首条消息内容"
```

取消插件原有的总条数 5 条上限和跳选序号 100 的上限，数量、序号必须是正整数。较多消息按每 5 条分张并依次发送；新一张会重新显示首位作者的昵称、标签和头像。若中途失败，命令消息会保留已发送的张数，方便确认进度。

## AIX 头像参考生图

回复一条消息，发送以下命令，同时参考被回复者和命令发送者的头像：

```text
.aix image aa 两个人一起喝茶，保留各自的外观特征
.aix image aa 2 两个人一起喝茶，生成不同的动作和表情
```

参考图顺序固定为：`IMAGE A` 是被回复者的头像，`IMAGE B` 是命令发送者的头像。可以额外附带最多 4 张图片，命令写在图片说明中。双头像模式沿用现有的提示词优化和多张生成设置；没有回复消息或任一头像无法获取时，会提示错误。

同时参考发布者头像和发布内容时，回复目标消息并使用 `ac`：

```text
.aix image ac
.aix image ac 把这条消息画成表情包，保留原话
.aix image ac --n 2 根据这条消息画出不同的动作和表情
```

`ac` 使用被回复消息发布者的头像，以及该条消息的原文、图片或贴纸；相册会读取同组消息的文字和图片。不填写额外提示词时，默认根据发布内容的主题、情绪或场景创作。`IMAGE A` 为发布者头像，后续依次为消息图片/贴纸与本次命令的附图，合计最多 6 张。原文会同时传入提示词优化与最终生图请求，关闭优化或失败重试时也会保留。没有回复、无法取得头像或消息没有可用内容时会报错。`avatar-content`、`头像内容` 与 `ac` 等价。

按消息序号选择头像时，回复起始消息，再输入 `p` 和用逗号分隔的序号：

```text
.aix image p 1,3 两个人一起喝茶
.aix image p 1,3 --n 2 两个人一起喝茶，动作和表情有所区别
.aix image p 3,1 两个人一起喝茶
```

被回复消息算第 1 条，按消息时间向后计数，只统计本次命令之前的普通消息，服务消息和 aix 命令不计入。同一人发的不同消息分别计数。`p 3,1` 会按这个顺序把第 3 条消息作者的头像作为 `IMAGE A`，第 1 条作者的头像作为 `IMAGE B`。重复序号只保留一次；同一作者的头像只下载一次。最多选 6 个头像，头像与额外附图合计最多 6 张。不存在的序号或无法获取的头像会明确报错；`pick` 与 `p` 等价，序号也可用中文逗号分隔。

素材读取支持 `.aix stop` 和 `.aix timeout 秒数`；旧相册会围绕被回复消息查询，查询失败时保留原图。提示词优化完成后立即开始生图，优化结果消息独立保留 10 秒。多张生成一次优化所有提示词，格式、数量或重复内容不合要求时使用原提示词继续生成。参考图在重试中复用，不再退回丢失头像参考的纯文生图。生成中途超时会交付已完成的图片，主动停止则终止后续处理。过长提示词会单独发送，避免图片说明过长导致图片发送失败。

## 安装插件

```text
.tpm i tj
.tpm i aix
.tpm i stsave
.tpm i ban_ad_spam
.tpm i yvlux
```

## 更新插件

```text
.tpm update
```
