# TeleBox-Plugins

基于 [Wyatt323/TeleBox-Plugins](https://github.com/Wyatt323/TeleBox-Plugins) 维护，包含文字语录玻璃气泡样式调整。

## 添加插件仓库

在 TeleBox 聊天中发送：

```text
.tpm source add https://github.com/xiangwan6667/TeleBox-Plugins
```

查看当前自定义源：

```text
.tpm source
```

## 插件功能

| 安装名 | 命令 | 功能简介 |
| --- | --- | --- |
| `tj` | `.tj` | 统计指定消息的全部回复，列出回复用户、时间和消息内容。 |
| `aix` | `.aix` | AI 对话、绘图、模型与提示词等 AI 功能。 |
| `stsave` | `.stsave` / `.st` | 保存贴纸，或将回复的图片、视频等媒体转换后保存到贴纸包。 |
| `ban_ad_spam` | 自动监听 | 别人回复消息并 @你 且包含 `ban广告` 时，自动对目标消息回复 `/spam`。 |
| `yvlux` | `.yvlux` | 根据消息生成语录贴纸，并支持保存到贴纸包。 |

`yvlux` 的文字语录默认使用深紫渐变的玻璃气泡：大圆角、气泡尾巴、细描边和顶部高光，头像靠下对齐，昵称保留发送者的强调色。绘图由 [Quote API](https://github.com/LyoSU/quote-api) 的 `glass` 样式完成，贴纸外围保持透明。

气泡按参考图保持紧凑比例：内边距从约 16px 微增至 18px，圆角约 27px，高光和描边沿用原样式。昵称完整显示且不换行，当前群的成员标签或管理员头衔在旁边以小号文字显示，无底色、无边框。长昵称会撑宽气泡，整张语录统一缩放，保持昵称、标签、正文的字号比例。优先读取消息自带的标签，再查询群成员信息。转发消息不套用转发者的群标签，查不到标签时正常生成。新成员标签需要宿主的 `teleproto` 支持对应 Telegram 协议字段。

背景使用宽柔光、轻微的明暗层次和约 7% 的局部透光，细颗粒强度很低，高光和描边保持原来的粗细。标题文字通过同一绘图接口批量绘制，再由插件完整排版，并缓存最近 64 组昵称与标签以减少重复请求。

默认文字接口为 `https://quote.yuri.ly/generate.webp`，真实头像由插件在本地合成（使用宿主已有的 `sharp`）；带媒体的语录仍走原增强版接口。手动配置过 API 的用户会继续使用自己的地址，后端需要支持 `style: "glass"` 才能呈现同样质感。回复消息发送 `.yvlux` 即可生成；发送 `.yvlux api reset` 可恢复默认接口。

## 语录模式与组合

以下生成命令都需要回复一条消息。以该消息为起点，按实际消息的时间顺序计数，排除语录命令和服务消息。

| 模式 | 命令 | 说明 |
| --- | --- | --- |
| 单条 | `.yvlux` | 生成回复的消息 |
| 连续选取 | `.yvlux 12` | 连续选取 12 条，每 5 条自动生成一张 |
| 跳选 | `.yvlux p 1,6,8` | 按实际消息序号选取；旧的 `pick` 写法仍兼容 |
| 带引用 | `.yvlux r 3` | 选取 3 条，并显示它们的回复引用内容 |
| 改名 | `.yvlux n "新名字"` | 修改首条所选消息作者在本次语录中的显示名，同一作者后续消息沿用 |
| 自定义文字 | `.yvlux t "新的内容"` | 替换首条所选消息的文字 |
| 原有自定义写法 | `.yvlux 新的内容` | 直接输入文字仍然可用 |
| 保存贴纸 | `.yvlux s` | 回复图片或贴纸，保存到已配置的贴纸包 |
| 查看帮助 | `.yvlux help` | 查看命令与组合示例 |

连续选取与跳选二选一；`r`、`n`、`t` 可以与任意一种选取方式叠加，选项顺序可变。包含空格或与选项同名的名字、文字，请使用引号。`s`、`config`、`api` 单独使用。

```text
.yvlux 12 r n "新名字"
.yvlux p 1,6,8 n "新的 昵称"
.yvlux r p 1,6,8 n "新名字" t "替换首条消息内容"
```

取消插件原有的总条数 5 条上限和跳选序号 100 的上限，数量、序号必须是正整数。较多消息按每 5 条分张并依次发送；新一张会重新显示首位作者的昵称、标签和头像。若中途失败，命令消息会保留已发送的张数，方便确认进度。

## AIX 双头像生图

回复一条消息，发送以下命令，同时参考被回复者和命令发送者的头像：

```text
.aix image aa 两个人一起喝茶，保留各自的外观特征
.aix image aa 2 两个人一起喝茶，生成不同的动作和表情
```

参考图顺序固定为：`IMAGE A` 是被回复者的头像，`IMAGE B` 是命令发送者的头像。可以额外附带最多 4 张图片，命令写在图片说明中。双头像模式沿用现有的提示词优化和多张生成设置；没有回复消息或任一头像无法获取时，会提示错误。

## 安装插件

```text
.tpm i tj
.tpm i aix
.tpm i stsave
.tpm i ban_ad_spam
.tpm i yvlux
```

## 更新插件

```text
.tpm update
```
