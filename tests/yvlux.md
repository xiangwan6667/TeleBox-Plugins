# yvlux 检查

Node.js 22+，需要 `typescript` 和 `sharp`。`YVLUX_TEST_DEPS` 可指向单独安装依赖的目录。

```text
node tests/yvlux.test.cjs
```

默认完全离线，使用本地图片和模拟 Telegram 客户端：

- 144 组：单条/连续/p 跳选 × r/n/t 的 8 个子集 × 文本/照片/贴纸/视频/TGS/GIF 缩略图。
- 检查实际输出的玻璃透明度、头像/媒体像素、512px 尺寸、无框群标签数据和改名范围。
- 检查参考图的左暗右亮紫色渐变、细顶部高光，以及原文字背景与本地气泡衔接处没有明显色阶。
- 检查先按实际内容裁边、头像约放大 16%；最终等比缩放保证一边恰为 512px，发送的尺寸属性与实际图片一致，可用于贴纸包。
- 检查正文实际字形放大、正文行宽收紧；姓名按 24px 与约 28px 正文配比并完整单行显示，引用图片随正文一起放大并正确对齐。
- 一次命令最多选择五条消息，连续数量及 p/pick 组合均验证；超限时不拉取历史、不调用绘图。跳选位置可超过五（例如 p 1,6,8,101,200）。
- 检查右下角时间浮层区域透明；已有空位直接复用，仅需要时补底部空间，不添加两侧或顶部空白。覆盖短小、极宽、窄长及自然空角图片。
- 覆盖完整单行姓名、短气泡、同人分组、服务消息/消息 ID 空洞、原生局部引用、原消息不被修改、上传失败进度与文件清理。
- 检查 help/config/api/s；保存图片时验证上传文件形状、`UploadMedia` 和 `InputDocument`，覆盖新建/追加以及原始静态/TGS/视频贴纸。
- 检查纯表情（含旗帜、肤色、ZWJ、键帽）、空消息，以及后端漏掉消息、缺少头像、气泡粘连三种异常；验证逐条恢复后仍是同一张图片，姓名/标签与消息对应、字号比例一致、同人分组只保留一个头像。
- 解析单条/连续/p × r/n/t/g 的 48 种组合；验证自定义标签、`g ""` 隐藏、首条作者范围和异常恢复后的标签保留，并检查帮助菜单长度。
- 18 组单消息完整生成：r/n/t/g 的全部 16 个子集，以及显式数量 1、仅跳选第二条；核对姓名、正文、标签、引用均作用于所选消息且原消息不被修改。
- 覆盖原样命令 `.yvlux n 111 t 111 g 111`、36 种选项顺序和选择器/引用组合、带空格参数、中文引号、复制产生的选项控制符；正文中的 Emoji ZWJ 保持不变。
- 验证群标签随气泡右边缘移动、姓名始终靠左；标签保持无框、单行、共同基线，长姓名和标签均不截断。
- 管理员/群主标签使用绿色，普通成员标签保持原色；覆盖消息自带头衔、`g` 自定义标签、身份查询失败回退与角色颜色缓存隔离，并检查姓名颜色不被修改。

只跑基础检查和布局恢复回归（不跑 144 组矩阵）：

```text
node tests/yvlux.test.cjs --layout-only
```

加 `--combo-live` 可用真实绘图接口检查数字姓名/正文/标签的原样组合、空格和复制控制符，以及右对齐标签。可与 `--layout-only` 一起使用，`YVLUX_PREVIEW_DIR` 保存预览。

加 `--tag-live` 可为自定义/隐藏标签的定向检查调用真实绘图接口（Telegram 仍使用模拟客户端）。

访问真实默认绘图接口，使用合成照片跑 24 组生成组合：

```text
node tests/yvlux.test.cjs --live
```

另有单条图片引用、局部引用和从第二条开始跳选的定向检查。真实接口检查仍使用模拟 Telegram 客户端，不读取 Telegram 登录信息、不发送消息、不创建或修改真实贴纸包。设置 `YVLUX_PREVIEW_DIR` 可保存完整组合模式及图片引用的预览。

安装 ffmpeg 后，加上 `--media-tools` 可验证无缩略图 MP4/WebM 的真实首帧提取和 GIF 解码。无缩略图 TGS 转码另依赖宿主的 Python rlottie；当前环境缺少该依赖，这条路径未做运行验证。动画在语录中显示静态预览，`s` 对已有贴纸保留原始文件。
